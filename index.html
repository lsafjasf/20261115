QUICK GUIDE

如何完成一次测量

  1. 拖拽声源与监听器，拖动头部圆环改变监听朝向。
  2. 切换单源、双源或四声道；选择吸声系数改变衰减时间。
  3. 点击“测量当前位置”离线渲染 IR，或“三点自动测量”完成整组校准。
  4. 检查反射图、到达延迟与实测结果的误差，随后导出 JSON / CSV。

TDOA 取激活声道首达耳的相对时间差。所有 IR 均由 Web Audio 的 OfflineAudioContext 渲染，测量值从渲染波形中检测。
